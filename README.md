# Omni All Shorts

**Omni All Shorts** is a personal YouTube automation tool used exclusively by its owner to schedule and upload videos to personally owned and managed YouTube channels via the YouTube Data API v3.

## Purpose
- Automated uploading of videos to authorized personal YouTube channels
- Automated management of video metadata (title, description, tags, and privacy status)

## Contact
For any questions or support regarding this application, contact: **mp3boyan@gmail.com**

## Privacy Policy

*Last updated: November 2026*

Omni All Shorts respects user privacy and adheres to the Google API Services User Data Policy, including the Limited Use requirements.

### 1. Data Collection and Usage
- This application is used solely for personal automation by its owner (`mp3boyan@gmail.com`) across personally owned YouTube channels.
- The application is not offered to external public users or third parties.
- OAuth 2.0 tokens and YouTube API scopes (such as `youtube.upload` and `youtube`) are used strictly to upload videos and update video details on the authorized channels.

### 2. Data Storage and Sharing
- No user data, channel analytics, or credentials are sold, rented, shared, or transferred to any third parties.
- OAuth credentials and refresh tokens are stored securely in private encrypted environment secrets strictly to execute scheduled uploads.

### 3. Revoking Access
- Access granted to any connected Google account can be reviewed or revoked at any time from [Google Account Security Permissions](https://myaccount.google.com/permissions).
